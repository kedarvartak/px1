# px1

A read-only code review workspace for changes an agent wrote: the diff since the
task began, plain-language notes on what changed and why, and the controls to
accept, question, or correct them.

```sh
npx px1-cli            # review the current directory
npm install -g px1-cli # then: px1 /path/to/repo
```

The command is `px1`. It serves a local web UI and opens it in your browser;
nothing leaves the machine. Full documentation:
https://github.com/kedarvartak/px1
